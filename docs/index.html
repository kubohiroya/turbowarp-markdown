TurboWarp Markdown

TurboWarp Markdown builds Markdown as immutable structured fragments. Blocks create escaped inline fragments, block fragments, lists, and sequences; final Markdown text is produced only by an explicit render block.

Core Flow

heading [1] [Sensor]
paragraph [temperature]
[heading result] followed by [paragraph result]
render Markdown [combined result]

Safety Model

  • Plain text is escaped instead of treated as raw Markdown.
  • Inline code and fenced code blocks choose deterministic delimiters.
  • Link destinations reject executable URL schemes such as javascript:.
  • No raw Markdown injection block is provided.

HTTP Server Interoperability

For turbowarp-http-server, pass the rendered string as the response body and set Content-Type: text/markdown; charset=utf-8. The HTTP server does not need to depend on this package.

TypeScript API

The package also exports block-free builder functions from @kubohiroya/turbowarp-markdown, including text, bold, italic, link, heading, paragraph, quote, codeBlock, listItem, unorderedList, orderedList, concat, and render.

固定入力の編集

対応GUIの固定入力機能は既定OFFです。既存値は開いただけでは変更せず、reporter接続は評価・置換しません。新しい選択と有限JSON数値入力のみを検証して保存し、既存の補正・丸め処理を維持します。機能OFFで従来の編集へ戻せます。
